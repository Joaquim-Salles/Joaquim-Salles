### &nbsp;&nbsp;`O QUE EU CONSTRUO`

> Sistemas end-to-end que eliminam dependência de processos manuais.  
> O projeto termina quando o cliente para de gerenciar — e passa a comandar.  
>   
> Trabalho com **Claude Code**, **Gemini** e **MCP servers** pra fazer em horas  
> o que antes levava semanas. Stack que respeita o usuário final
